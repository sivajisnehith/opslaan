# ⚓ opslaan
**Anchor your conversations.**

**opsilaaan** is a lightweight browser extension built **exclusively for ChatGPT** that helps you **anchor, pin, and navigate important parts of long conversations**.

When ChatGPT chats become lengthy and hard to manage, opsilaaan gives you structure — so you can jump back to key points instantly without endless scrolling.

## ✨ Features
- ⚓ Create anchors for important ChatGPT messages
- 📌 Jump instantly to saved anchors
- 🧭 Navigate long ChatGPT conversations easily
- 🚀 Fast, minimal, and distraction-free
- 🔒 100% local — no tracking, no data collection

## 🧩 How to Install (Chrome – Manual / Developer Mode)

### Step 1: Download the extension
- Download or clone this repository
- Ensure the folder contains:
  - `manifest.json`
  - JavaScript / CSS files
  - `icons/` folder

---

### Step 2: Open Chrome Extensions page
1. Open Chrome
2. Navigate to:
3. Enable **Developer mode** (top-right)

---

### Step 3: Load the extension
1. Click **Load unpacked**
2. Select the **opsilaaan** folder
3. The extension will load instantly 🎉

---

### Step 4: Use the extension
1. Open https://chat.openai.com
2. Start a conversation
3. Add anchors using opsilaaan
4. Jump back to important points anytime
